# Input Videos

## Welcome
Greetings, and welcome to the `input_videos` directory! Here, you'll find a designated space for storing videos tailored for video training or data extraction for further operations.

## Usage Instructions
Kindly save your video files within this repository if they are intended for any of the following purposes:
- Training machine learning models utilizing video data.
- Extracting features or data from videos for processing purposes.

## Best Practices
To ensure seamless processing and optimal organization, please stick to the following guidelines:
- Ensure video filenames are clear and descriptive, facilitating easy identification.
- Recommended filename format: `exerciseName_cameraId_personId_features` (e.g., `barbell_dead_row_65906101_s05_13ang.mp4`).

## Additional Notes
- It is advisable to utilize standard video formats such as MP4, AVI, or MOV for enhanced compatibility and usability.
